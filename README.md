# 🚀 Projeto Principal

## Gestão IPDA Caxias (SaaS)

Sistema completo desenvolvido para gestão administrativa de igreja, utilizado em ambiente real.

### Principais recursos

✔ Cadastro completo de membros

✔ Controle de participação na Santa Ceia

✔ Dashboard com estatísticas e indicadores

✔ Sistema de auditoria de alterações

✔ Controle de permissões por níveis (roles)

✔ Upload de imagens com Cloudinary

✔ Exportação de relatórios em Excel

✔ Relatórios administrativos

✔ Autenticação e autorização de usuários

### Tecnologias

* Next.js
* React
* TypeScript
* Firebase Authentication
* Firestore
* Cloudinary
* Tailwind CSS
* React Hook Form
* Zod
* ExcelJS
* Git e GitHub
